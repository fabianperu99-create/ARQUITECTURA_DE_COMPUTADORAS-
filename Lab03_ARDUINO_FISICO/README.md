# Lab 03: Programación y Conexión con Arduino UNO

## 📌 Descripción
En este laboratorio trabajamos con Arduino UNO y protoboard. 
Conectamos LEDs, resistencias y DIP Switch para controlar salidas digitales
y probar el funcionamiento del circuito.

## 🎯 Objetivo
Aprender a conectar Arduino con componentes externos y programar el 
encendido de LEDs usando entradas digitales.

## 🛠️ Materiales Utilizados
- **Placa**: Arduino UNO
- **Protoboard**: 1 unidad
- **Componentes**: LEDs, Resistencias 220Ω, DIP Switch de 4 pines
- **Cables**: Jumpers macho-macho
- **Software**: Arduino IDE

## 📋 Procedimiento
1. Conectamos el Arduino UNO a la PC vía USB
2. Armamos el circuito en el protoboard según el esquema
3. Cargamos el código en Arduino para controlar los LEDs
4. Probamos cambiando las posiciones del DIP Switch
